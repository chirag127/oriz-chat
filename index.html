This is the about / info page for oriz Chat — not the app itself. The live tool lives at chat.oriz.in.

What it is

A free, streaming AI chat app that runs entirely in your web browser. Multi-turn conversations, a full model picker with automatic multi-provider failover, sanitized markdown rendering, on-device history, prompt presets, and export — with no backend, no account, and no API key.

Features

  • Any model, auto failover — full g4f model picker; retries another provider if one is down.
  • Prompt presets — general, code, brainstorm, explain, rewrite, translate.
  • Markdown + code — sanitized markdown with fenced code, tables, lists.
  • Private history — conversations saved to IndexedDB on your device; browse, reopen, delete.
  • Export — download any chat as Markdown or JSON.
  • Drag & drop — drop a .txt/.md file into the composer as context.

Tech

  • Client-only Astro (static) + React 19 islands + Tailwind v4.
  • AI via g4f through @chirag127/oz-ai — keyless multi-provider client.
  • PWA-installable; offline app shell.
  • 100% in-browser — no upload, no signup, no telemetry.

Privacy

No backend, no accounts, no telemetry. The only network calls are the AI completion requests you initiate. History and exports stay on your device.
